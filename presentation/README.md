# Pitch Deck & Demo Materials

## Files

- `pitch_deck.html` - slide HTML chính để nộp BTC và trình chiếu trong 3 phút.
- `pitch_deck.md` - outline/source nội dung của deck HTML.

Video demo được lưu qua link Google Drive trong README/checklist vì file video thường lớn.

## Pitch Deck Structure (6 slides)

1. **Title** - Ocean Park AI Advisor + value proposition.
2. **Core Problem** - khách mua nhà không thiếu thông tin, họ thiếu câu trả lời đủ tin để ra quyết định.
3. **User Pain** - pain points của khách mua và đội Sales.
4. **Product Solution** - luồng pre-sales từ câu hỏi đến CRM.
5. **Trust Layer** - RAG/citation, guardrails, CRM context ở mức ngắn gọn.
6. **Live Demo Bridge** - dẫn sang demo public app, RAG chat, lead capture và admin CRM.

## How To Present

- Dùng `presentation/pitch_deck.html` để trình chiếu trực tiếp trên browser.
- Phím `ArrowRight`, `Space`, `PageDown`: sang slide tiếp theo.
- Phím `ArrowLeft`, `Backspace`, `PageUp`: quay lại slide trước.
- Phím `N` hoặc nút `Notes`: bật/tắt speaker notes.
- Có thể in/export PDF từ browser bằng `Ctrl+P`.
